安装运行、调试说明：

1、下载DevEco:https://developer.huawei.com/consumer/cn/download/

2、本地安装模拟运行环境：

1）本地打开DevEco，打开该项目

2）点击下图中的No device按钮

<img width="192" height="26" alt="image" src="https://github.com/user-attachments/assets/6620256d-afda-46af-ad9c-cd41ce760405" />

3）选择安装的模拟环境，如下图所示，点击Actions进行安装

<img width="760" height="446" alt="image" src="https://github.com/user-attachments/assets/137ccaa4-b272-482a-b7dd-2718be445ee1" />

4）安装完毕后，选择mate60运行环境，并且点击下图的绿色三角形运行按钮

<img width="807" height="416" alt="image" src="https://github.com/user-attachments/assets/4abcdddf-5b74-4060-9fbd-e75d0d796476" />

5）运行时，会弹出真机模拟环境，如下图所示

<img width="407" height="437" alt="image" src="https://github.com/user-attachments/assets/a0e69d1b-1b0d-41b3-9905-c9aca147c027" />

3、回到DevEco项目主页，点击右上角的运行按钮，如下图

<img width="218" height="29" alt="image" src="https://github.com/user-attachments/assets/4efa3d5a-ca71-4ec7-9b60-de281ac929a8" />

4、可在真机模拟环境中看到antennaPod app。点击运行如下图

<img width="218" height="418" alt="image" src="https://github.com/user-attachments/assets/a08d51f6-41ed-4554-a2f7-6e73efdfee8e" />
